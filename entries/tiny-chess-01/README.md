# chess-entry

A 4 KB Python chess engine for make.fun's tiny-chess-01: mailbox board mirrored each ply, Michniewski piece-square tables (endgame king table when material is low), alpha-beta with PVS, late move reductions, null move, killers, history, check extension and quiescence, to a fixed node budget. main.py is the LZMA-packed source.
